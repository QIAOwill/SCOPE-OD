# SCOPE-OD
SCOPE-OD is a semantic-control framework for intercity OD flow forecasting. It encodes uncertainty-aware origin, destination, and pairwise semantic priors, combines them with daily regime contexts, and generates dynamic controls to guide OD interaction learning, while enforcing semantic consistency in latent OD states.
